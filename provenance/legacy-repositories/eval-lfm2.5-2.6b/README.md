# lfm2.5-2.6b-qad

WumboLabs model-evaluation campaign (WumboJetsII host).

- **Verdict:** QAD Q4_0 is the rational ultra-fast deployment quant when 1.59 GB is the hard size target; it retained PTQ Q4_0 footprint and throughput (282.5±0.4 t/s) and improved fixed-corpus perplexity, but the campaign did NOT reproduce a material practical-quality win over PTQ Q4_0 nor the 96.6% retention claim.
